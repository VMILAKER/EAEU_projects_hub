# Description
The repository was created for the purpose of highlighting joint projects of the Russian Federation and the Republic of Belarus in the scope of Eurasian Economic Union.

The final product is DB filled with project's data. One of the core functions is RAG-system support with RRF and llama3.2 as LLM.
